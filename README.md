# Frontline 1985 / 前线 1985

一辆坦克，一座基地。守住你的最后一道防线。

一款使用 **HTML5 Canvas、原生 JavaScript 和 CSS** 制作的单人坦克大战。军绿色街机界面、可破坏地形、三波敌军和实时战况，打开浏览器即可游玩。**无需安装依赖，无需构建，支持离线运行。**

## 开始游戏

下载项目后，直接双击 `index.html`，点击 **开始作战** 或按 **Enter**。

也可以在项目目录运行本地静态服务器：

```sh
python -m http.server 8765
```

然后在浏览器中打开 <http://localhost:8765>。使用较新的 Chrome、Edge、Firefox 或 Safari；音效在开始游戏后启用，浏览器不允许音频时仍可正常游玩。

## 操作

| 操作 | 键盘 / 界面 |
| --- | --- |
| 移动 | `W A S D` 或方向键 |
| 射击 | 长按 `空格` 持续发射 |
| 开始 / 继续 | `Enter` 或屏幕上的按钮 |
| 暂停 / 继续 | `P` 或暂停按钮 |
| 开关音效 | `M` 或音效按钮 |
| 重新开始 | 战场工具栏中的重新开始按钮 |
| 手机 / 平板 | 战场下方的方向键与 `FIRE` 键，可同时按住移动和射击 |

切换窗口或隐藏页面时，游戏会自动暂停。操作指南可从页面右上角打开。

## 战役规则

- 清除 **3 波敌军**，每波分别为 **8、10、12 辆**。后续波次会出现需要两发炮弹才能击毁的装甲坦克。
- 初始拥有 **3 条生命**，被击毁后会重新部署，并获得短暂护盾。生命耗尽或基地被击毁即告失败。
- 基地位于战场下方，友军炮弹不会摧毁基地；围墙仍可被炮弹击碎，开火时注意防线。
- 普通敌军价值 **100 分**，装甲敌军价值 **200 分**。通关后，每条剩余生命额外奖励 **500 分**。
- 每击毁 4 辆敌军会获得随机补给，驾驶坦克靠近即可拾取。补给存在时间有限。

| 补给 | 效果 |
| --- | --- |
| 护盾 | 9 秒内抵御敌军炮弹 |
| 速射 | 12 秒内提高发射速度 |
| 维修 | 恢复一条生命，最多 3 条，并修复基地围墙 |

| 地形 | 特性 |
| --- | --- |
| 砖墙 | 阻挡坦克与炮弹，可被击碎 |
| 钢墙 | 阻挡坦克与炮弹，不可摧毁 |
| 丛林 | 可以穿行，遮挡坦克外观 |
| 水域 | 坦克无法通行，炮弹可以穿过 |

最高分保存在当前浏览器的本地存储中，不会上传服务器。浏览器禁用存储时，游戏仍可运行。

## 项目结构

```text
.
├── index.html   # 页面、战况面板、帮助弹窗与触屏按键
├── style.css    # 街机视觉、响应式布局与交互状态
├── game.js      # Canvas 绘制、坦克 AI、碰撞、波次、道具与合成音效
├── main.js      # 界面更新、键盘 / 触屏输入、暂停与游戏生命周期
├── favicon.svg # 浏览器图标
├── README.md
└── LICENSE
```

游戏引擎通过 `window.TankGame` 提供开始、重开、暂停、静音与输入接口，通过回调向界面报告战况、战地消息和结算结果。所有图形与音效均在浏览器内生成，不需要图片或音频资源。在线时加载 Google Fonts，离线时自动回退到系统字体，不影响游玩。

## 验证

安装了 Node.js 时，可运行无需第三方依赖的玩法测试：

```sh
node tests/smoke.cjs
```

覆盖移动、射击、地形碰撞、积分、最高分、基地防守、重生、暂停、补给和波次结算。

## 使用 GitHub Pages 发布

将项目文件上传到仓库的 `main` 分支根目录后：

1. 打开仓库的 **Settings → Pages**。
2. 在 **Build and deployment** 中选择 **Deploy from a branch**。
3. 选择 **main** 分支和 **/ (root)** 目录，点击 **Save**。
4. 等待 GitHub Pages 部署完成，使用页面显示的访问地址打开游戏。

这是纯静态网站，不需要构建命令、环境变量或服务器数据库。
